# Spike LLM — Investigação Direta (V0)

Experimento independente de baseline cognitivo: enviar arquivos originais à OpenAI e fazer **uma** pergunta aberta em uma única chamada de análise. Sem motor de extração, agentes, busca vetorial ou classificação prévia.

A implementação e as instruções ficam na branch `feat/direct-file-baseline`. Os documentos e resultados permanecem **fora do Git** no computador do operador.

**Estado:** implementação experimental; nenhuma chamada paga ou upload é realizado automaticamente.
